# 海街手帖 · 动漫风手账相册

**线上地址（永久，手机直接打开）**：https://xgp-666.github.io/haijie-shoutie/

**动漫海街风 + 贴纸剪贴风**的纯静态手账相册：奶油色纸纹理、甜美和纸胶带、白色 die-cut 剪贴边照片、AI 手绘贴纸（叶子 / 爱心）与矢量贴纸（电车 / 紫阳花 / 云 / 帆船 / 道口标志）、日文行李牌、虚线贴纸按钮、动画电影感封面。移动端 / 电脑端自适应，**无需数据库、无需构建**，整个目录上传到任意静态托管即可访问。

## 网站上能直接改什么

全部在网页上操作，不用碰代码（改完只存在这台设备，需要长期生效请看下面「手动同步」）：

| 想改的东西 | 怎么改 |
| --- | --- |
| 回忆照片 / 文字 | 时间线每页右上角 **「改」**；右下角 **「＋ 写一页」** 贴新页 |
| 封面大图 | 直接**点封面照片**，或页脚「换封面」 |
| 轮播图 | 轮播下方 **「换图」**：点缩略图换照片，小字直接打字改 |
| 页面文字 | 相册名、副标题、手写英文、页脚等**点一下就能改** |
| 配色 / 明暗 / 字体 | 页脚 **「换主题」**：5 套预设、六个色值手输、字体手输 |
| 撕掉一页 | 卡片右上角 **「×」** |

## 手机上改完，怎么让别的手机也看到（手动同步）

照片存在各自浏览器里，静态网站不能自动同步，用这个流程固化：

1. 手机上做任何改动（上传照片 / 换封面 / 换轮播 / 换主题 / 改文字）
2. 页脚点 **「固化到相册」** → 下载 `memories-from-phone.js`
3. 在手机「文件 / 下载」里找到它，用微信 / QQ / 邮件发到电脑
4. 电脑上打开，按文件里的注释把每段粘到 `assets/js/data.js` 对应位置（MEMORIES / SITE.cover / SLIDES / PALETTE / SITE 文字），保存
5. 整个目录重新上传到静态托管（GitHub Pages / Vercel / Netlify / 腾讯云静态托管）

粘好后，**任何手机、任何浏览器打开网站都能看到这些照片**——它们已经变成网站本身的一部分。

之间想在别的设备临时看，也可以用「导出备份」+「导入备份」传 `.json`。

## 手机上传照片

1. 手机打开网页，点右下角 **「＋ 写一页」**；
2. 选照片（手机上可直接**拍照**或从相册选择），填上时间、标题、随笔、标签；
3. 点「贴上去」，照片会**自动压缩**并贴到时间线最上方，带「×」可随时撕下。

上传的照片保存在**本机浏览器**（IndexedDB，不可用时自动降级到 localStorage）：

- 同一台手机的同一浏览器、用**同一个网址**打开，刷新、关掉再打开都在；
- 换手机 / 换浏览器 / 换网址不会自动同步——用上面的「手动同步」或「导出备份 / 导入备份」；
- 想让所有设备实时共享同一本相册，需要额外接一个云存储 / 后端服务（静态托管做不到）。

## 怎么改内容（只改 data.js）

| 位置 | 作用 |
| --- | --- |
| `SITE` | 扉页大图、手写英文、相册名、副标题、页脚 |
| `PALETTE` | ★ 海街色板：6 个颜色，整站配色一键换（胶带、标签、阴影、贴纸、时间轴） |
| `FONT` | 中文字体（楷/宋/黑）、英文手写字体、字号、行距（不用改 CSS） |
| `SLIDES` | 轮播图（`SLIDE_INTERVAL` 设 0 可关掉自动播放） |
| `MEMORIES` | 时间线每条回忆：时间、标题、随笔、照片、手写英文、日文行李牌 `jp`、标签 |
| `CATEGORIES` | 留空 = 自动收集所有标签；也可手动指定顺序 |

### 换照片

照片放进 `assets/images/` 后改路径，或直接填外链：

```js
image: 'assets/images/photo-01.jpg',
```

建议横版 4:3，单张 500KB 以内加载更快。

### 加一条回忆

复制 `MEMORIES` 里任意一段修改即可：

```js
{
  date: '2026 · 四月',
  title: '标题',
  text: '随笔，用 \n 换行',
  image: 'assets/images/x.jpg',
  script: 'a slow afternoon',   // 手写英文点缀，可留空
  tags: ['日常']
}
```

胶带颜色、照片微倾角度、色卡贴纸会自动轮流出现，不用配置。

### 换配色（海街色板）

改 `data.js` 里的 `PALETTE`，整站颜色（胶带、日期标签、照片彩色阴影、分类按钮、贴纸、时间轴）会全部跟着变：

```js
const PALETTE = ['#6ea8c9', '#4a7043', '#e5c85a', '#c9a3c4', '#4a7fa5', '#d98e73'];
const TAPE_ALPHA = 0.62;   // 胶带浓度
const USE_STICKERS = true; // 海街贴纸：电车 / 紫阳花 / 云 / 帆船 / 道口标志
```

现成搭配：

- 镰仓夏日 `['#6ea8c9','#4a7043','#e5c85a','#c9a3c4','#4a7fa5','#d98e73']`
- 黄昏列车 `['#e8a468','#5b7fa5','#d9777f','#8a9b68','#c9b458','#6ea8c9']`
- 雨后紫阳花 `['#8fa8c9','#c9a3c4','#7d9b8a','#6d84a8','#b7c9a8','#d9b0c4']`
- 动画黄昏 `['#f2a65e','#5d84b0','#c96f6f','#88a878','#e8c97a','#7a94b8']`

## 功能

- 扉页拍立得封面 + 手写标题，缓慢淡入
- 纵向时间线：拍立得白边照片 + 和纸胶带 + 牛皮纸日期标签 + 手写英文点缀，滚动渐显
- 照片点击放大（← → 翻页、ESC 关闭、手机滑动）
- 分类标签筛选（自动收集，含手机上传条目的标签）
- 轮播相册页（自动播放、悬停暂停、箭头 / 圆点 / 滑动）
- 时间线每页「改」：改文字 + 换照片（手机上直接操作）
- 轮播「换图」：换照片 + 改英文小字
- 封面点击换图 / 页脚「换封面」
- 页面文字点击直改（相册名、副标题、手写英文、页脚…）
- 「换主题」：5 套配色预设、六个色值手输、明暗、字体
- 「固化到相册」：把本机改动一次性导出成 data.js 片段
- 手机「写一页」上传照片（本地保存 + 自动压缩 + 可删除）
- 备份导出 / 导入（JSON，含全部上传照片）
- 浅色 / 深色一键切换（自动记住），已适配 `prefers-reduced-motion`

## 手机站点（加到桌面当 App 用）

网站本身就是一个 PWA，手机上可以「安装」：

- **Android / Chrome**：打开网页 → 右上角 ⋮ → **添加到主屏幕 / 安装应用**
- **iPhone / Safari**：底部 **分享** 按钮 → **添加到主屏幕**
- 页脚也会自动出现 **「装到手机桌面」** 按钮（支持安装的浏览器才会显示）

装好之后：

- 像 App 一样**全屏打开**（没有地址栏），图标是这本相册的拍立得小图
- **离线可用**（`sw.js` 缓存了页面与图片），地铁上没网也能翻
- 照片仍存本机，上传 / 改字 / 换主题全部照常

> 注意：安装功能需要 `https://` 或 `localhost`（局域网 `http://192.168.x.x` 时部分浏览器会隐藏该按钮，用上面的手动步骤照样能加）。

## 部署上线（让两台手机随时都能打开）

推荐 **腾讯云 EdgeOne Makers**（专门发布静态网页）：

1. 在 CodeBuddy 里连接集成：**设置 / 集成 → EdgeOne Makers → 登录腾讯云授权**
2. 连好后跟助手说「已连接」，由助手一键部署整个目录
3. 部署完会拿到一个 `https://` 网址，两台手机都能打开，也能「添加到主屏幕」

也可以手动上传到任意静态托管（GitHub Pages / Vercel / Netlify / 腾讯云静态托管 COS 等）：
把**整个目录**（`index.html` + `assets/` + `site.webmanifest` + `sw.js`）原样上传即可，不需要构建。

> 上传到线上前，记得把本地预览用的 `serve.py`、临时图片等无关文件删掉。

## 本地预览

推荐用自带的快速服务器（长连接 + 多线程 + gzip，手机加载明显更快）：

```bash
python serve.py          # 默认 8081
python serve.py 9000     # 指定端口
```

也可以：

```bash
python -m http.server 8080
# 或
npx serve .
```

浏览器打开 `http://localhost:8081`。手机预览：保证手机与电脑同一 Wi-Fi，访问 `http://电脑IP:8081` 即可（上传、拍照功能都能用）。

> 注意：IndexedDB 在 `https://` 部署后按域名存储；直接双击打开本地文件也能看，但部分浏览器功能受限，建议用本地服务器或部署后访问。
